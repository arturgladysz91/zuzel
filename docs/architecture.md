# Architecture
- CoreSim: czysta logika symulacji (bez UI, bez IO, bez “telemetrii” dla gracza).
- Sandbox: uruchamianie symulacji, logi do konsoli, szybkie eksperymenty.
- Docs: źródło prawdy o pojęciach i regułach.
