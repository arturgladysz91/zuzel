# Speedway Manager – Wizja

Projekt ma docelowo odwzorować zarządzanie klubem żużlowym w ujęciu symulacyjno-strategicznym. W kolejnych fazach przewidujemy:

1. **Rozbudowę warstwy sportowej** – model zawodników (umiejętności, morale, formacje juniorskie), taktyki biegów, kontuzje.
2. **Ekonomię klubu** – kontrakty, sponsorzy, inwestycje w infrastrukturę, budżet.
3. **Narrację sezonu** – terminarz ligowy dla dwóch poziomów rozgrywek, playoffy, statystyki, progresja kariery.
4. **Warstwę wizualną** – UI zarządcze i uproszczona wizualizacja biegów.

Faza 1 koncentruje się na deterministycznym module fizyki jazdy. Tworzymy solidny fundament pozwalający w kolejnych krokach dodawać wpływ zawodników, pogody i taktyki.
