## B. Why throttle-only cannot exceed baseline full-drive

Ordinary ADVANCED Straight already evaluates the full available production drive envelope before the backward corner-preparation boundary. Multiplying that force by a throttle availability constrained to 0..1 cannot create a speed trajectory above the full-drive baseline. Therefore this experiment changes only the speed-dependent force multiplier shape; it is not a 70%→100% throttle ramp and is not interpreted as a real torque curve.
