# Stadion #192

Pole „Przejazd” zawiera archiwum biegów H25/FAST50 i dołączone nagrania. Nowe biegi używają symulatora #191 i są zapisywane w folderze Archiwum. Odtwarzacz pokazuje pozycje i kierunki motocykli odczytane z nagrania. Wyniki i kontakty pochodzą z symulatora. Prędkość animacji zmienia jedynie tempo odtwarzania.
